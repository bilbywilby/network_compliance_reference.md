**In tvOS app:**
1. **Exit Node** section → Select **Run as Exit Node**
2. **Subnet Router** section → Advertise `192.168.0.0/24`
3. Approve both roles in admin console

**Use case:** Remote users route *all* traffic through your home IP (exit node) while simultaneously accessing internal LAN resources (subnet router).

⚠️ **Warning:** <citation src="7"></citation> Do **not** run remote network speed tests on the Apple TV. High-throughput operations (Ookla speed tests, large file transfers) can overwhelm the device and crash the network extension, dropping your Tailscale connection.

## 9. Troubleshooting

| Symptom | Cause | Solution |
|---------|-------|----------|
| Routes don't appear in admin console | tvOS < 1.90.9 or routes not saved | Update to 1.90.9+, press Save, wait 10s |
| Routes appear then disappear | App crash / network extension killed | Restart Tailscale app, ensure home hub enabled |
| Cannot ping devices on `192.168.0.0/24` | Routes not approved or firewall blocking | Check admin console approval, verify router firewall rules |
| Apple TV falls asleep mid-tunnel | Home hub not configured | **Settings > AirPlay & HomeKit > HomeKit**, assign room name |
| High latency (>200ms) | WiFi interference | Switch to ethernet cable for Apple TV |
| DNS not resolving | Split DNS misconfigured | Verify DNS settings in admin console match your resolver |

## 10. High-Availability Failover for Healthcare Data

For critical compliance workflows, set up **redundant subnet routers**:

<citation src="6"></citation>

**Multiple subnet routers strategy:**
- **Primary:** Apple TV advertising `192.168.0.0/24`
- **Secondary:** Linux device (Raspberry Pi) also advertising `192.168.0.0/24`
- **Longest prefix matching:** Use overlapping subnets for granular control (e.g., `/24` + `/32` for specific devices)

⚠️ **Caution:** <citation src="6"></citation> If both routers advertise the same prefix and one goes offline, traffic to that prefix is **dropped, not failed over**. To prevent this, configure both routers to advertise *both* the broad prefix (`/24`) and the specific prefix (`/32`) they serve directly.
